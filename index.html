User Manual & Technical Guide

1. Connectivity & I/O

Connect your MIDI controller via USB-OTG (Android) or USB (Windows). Use "Add MIDI Port" to create custom routing targets for hardware (Korg, JuziSound) or VSTs (Kontakt). Double-click ports to rename them for easy identification.

2. Combo Performance Mode

Layer multiple instruments in a single performance. Each slot features independent control over:

  • Volume & Transpose: Set levels and octaves per instrument.
  • Terca (Thirds): Enable the checkbox for specific slots to trigger harmonies automatically when the Terca button is active.
  • Panic: Instantly resets MIDI buffer and stops stuck notes.

3. Mapping & MIDI Learn

Customize your workspace without coding. Use Edit Mode for pads or Long-press (2s) on sliders and side buttons to assign MIDI CC, Program Changes (with MSB/LSB support), or SysEx messages. Use MIDI Learn to sync with your physical knobs instantly.

4. Microtuning (Scales)

Adjust tuning for any note from -100 to +100 cents by long-pressing the keys on the piano display. Save custom scales to your library or use the Favorite buttons (hold for 3s to save).

TECHNICAL NOTE: Microtuning is applied via real-time Pitch Bend messages. For accurate tuning, ensure your hardware synthesizer or VST instrument has its Pitch Bend Range set to 2.

5. Data Management

Save your entire configuration using the Diskette icon. For maximum safety, the app supports manual JSON text copying and easy loading from local storage.
